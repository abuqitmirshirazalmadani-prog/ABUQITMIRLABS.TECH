## SCHEMA MARKUP TO ADD (GEO/AEO)

Add this JSON-LD to every page listed above:

### BreadcrumbList (every page)
```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Home",
      "item": "https://www.abuqitmirlabs.tech"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "[Page Name]",
      "item": "https://www.abuqitmirlabs.tech/[page-slug]"
    }
  ]
}
```

### FAQPage (for pages with AEO direct answers)
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[Question from AEO section]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[Direct answer text -- 40-60 words]"
      }
    }
  ]
}
```

## GEO OPTIMIZATION RULES
Apply to every page listed above:

1. Har page pe ek 40-60 word direct answer paragraph add karo
   -- Start with the exact query as a question in H2 or bold
   -- Answer directly in first 2 sentences
   -- No preamble -- AI models extract direct answers

2. Har page pe structured data (schema) add karo
   -- FAQPage for pages with Q&A
   -- Service schema for service pages
   -- BreadcrumbList on every page

3. Statistics aur numbers add karo
   -- "410+ projects completed"
   -- "98% client retention"
   -- "Serving 10 countries"
   -- AI models cite specific numbers

4. Entity mentions add karo
   -- City names: Doha, Riyadh, Dubai, Karachi, London
   -- Technology names: Next.js, RAG, LLM, Flutter
   -- Industry names: Fintech, Healthcare, EdTech
   -- These help AI models understand context
